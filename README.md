- [Drone Data Parser](https://github.com/EricTannant/drone-data-parser): Python scripts for processing and analyzing DJI drone and 3D survey data, automatically converting drone images and coordinates into useful 3D point clouds.
- [Portfolio Website](https://www.erictannant.com): Personal Portfolio Website made using React, written in JavaScript using NodeJS for package management.
